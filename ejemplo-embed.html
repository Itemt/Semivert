Semivert Incrustado (Simulador de Orientación en Vivo)

📋 Elige el método para tu web urgente

📦 1. Iframe Directo (Recomendado)

Copia la carpeta semivert-web en tu servidor y pega este código en tu archivo HTML donde quieras que aparezca el juego. 

<!-- Semivert en tu HTML -->
<div style="width: 100%; height: 800px; border-radius: 16px; overflow: hidden; box-shadow: 0 10px 30px rgba(0,0,0,0.2);">
  <iframe 
    src="./semivert-web/index.html" 
    style="width: 100%; height: 100%; border: none;" 
    allow="camera" 
    loading="lazy">
  </iframe>
</div>

⚡ 2. Script Embed Automático

Incluye el script semivert-embed.js y coloca un contenedor con el atributo data-semivert-embed. 

<!-- 1. Cargar el script -->
<script src="./semivert-web/semivert-embed.js"></script>

<!-- 2. Contenedor automático -->
<div data-semivert-embed data-height="820px"></div>

🪄 3. Modal / Botón Flotante

Agrega un botón en cualquier parte de tu web que abra Semivert como ventana modal emergente con fondo difuminado. 

<script src="./semivert-web/semivert-embed.js"></script>

<!-- Botón para abrir modal -->
<button onclick="Semivert.openModal()">
  🌱 Jugar Semivert
</button>

<!-- O botón flotante permanente: -->
<script>
  Semivert.addFloatingButton();
</script>
